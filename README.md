# Лабораторная работа 1. Класс Matrix

Класс `Matrix` для работы с двумерными матрицами целых чисел с динамическим выделением памяти.

## Возможности
- Создание матриц: `0x0`, единичная `N x N`, прямоугольная `rows x cols` с нулями.
- Метод `transpose()` для транспонирования.
- Безопасная память (деструктор) и обработка ошибок (`std::invalid_argument`, `std::out_of_range`).

## Сборка и запуск
```bash
g++ -std=c++17 -Wall -Wextra main.cpp Matrix.cpp -o lab1
./lab1
