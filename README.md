# Лабораторная работа 4. Управление ресурсами: правило трёх

Класс `Matrix` с поддержкой динамического управления памятью, конструктором копирования и перегруженным оператором присваивания.

## Возможности
- Глубокое копирование через конструктор копирования.
- Безопасный оператор присваивания (`operator=`) с защитой от самоприсваивания и поддержкой цепочек.
- Рефакторинг работы с памятью через приватные методы (`allocate`, `copyFrom`, `freeMemory`).
- Корректная обработка пустых матриц (`0x0`).

## Сборка и запуск
```bash
g++ -std=c++17 -Wall -Wextra main.cpp Matrix.cpp -o lab4
./lab4
